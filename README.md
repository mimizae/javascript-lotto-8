# javascript-lotto-precourse

## 2주차 - 로또

### 구현할 기능 목록

간단한 로또 발매기를 구현한다.

- 사용자로부터 로또 구입 금액을 입력 받는다. 로또 1장의 가격은 1,000원이므로 구입 금액은 1,000원 단위로 입력 받을 수 있다.
  <br/>
  <br/>
- 이때, 1,000원으로 나누어 떨어지지 않는 금액일 시 ‘[ERROR] 1000원 단위로 입력해 주세요.’ 라는 Error와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
- 또한 사용자로부터 입력 받은 로또 구입 금액이 10만원을 초과한다면, ‘[ERROR] 1인당 로또 구입 금액은 10만원을 초과할 수 없습니다.’ 라는 Error와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
- 로또 구입 금액으로 숫자 외 다른 문자가 입력된다면, ‘[ERROR] 구입 금액에 숫자 외 다른 문자는 입력될 수 없습니다.’ 라는 Error와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
- 사용자로부터 로또 구입 금액을 입력 받았다면, 발행할 로또의 수량과 로또 번호를 출력한다. 이때, 각 로또 번호는 오름차순으로 정렬하여 보여준다.
  <br/>
  <br/>
- 이때, 로또 번호의 숫자 범위는 1부터 45까지이다.
  <br/>
  <br/>
- 다음으로, 사용자로부터 당첨 번호를 입력 받는다. 당첨 번호는 쉼표(,)를 기준으로 구분하며, 번호는 중복되지 않는 1과 45 사이의 6개 숫자여야 한다.
  <br/>
  <br/>
- 쉼표를 기준으로 나눈 값 중 1과 45 사이의 정수가 아니라면 ‘[ERROR] 당첨 번호는 1과 45 사이의 정수여야 합니다.’ 라는 Error와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
- 쉼표를 기준으로 나눈 값 중 숫자로만 이루어지지 않은 값이 있다면 ‘[ERROR] 숫자 외에는 입력할 수 없습니다. (공백, 문자, 특수문자 불가)’ 라는 Error와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
- 쉼표를 기준으로 나눈 당첨 번호 중 서로 중복되는 값이 있다면 ‘[ERROR] 당첨 번호는 서로 중복될 수 없습니다.’ 라는 Error와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
- 쉼표를 기준으로 나눈 값의 개수가 6개 미만이거나 초과한다면, ‘[ERROR] 당첨 번호는 6개를 입력해 주세요.’ 라는 Error와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
- 사용자에게 당첨 번호를 입력 받고 난 뒤, 보너스 번호 또한 입력 받는다.
  <br/>
  <br/>
- 이 값이 숫자 외의 값이라면 ‘[ERROR] 숫자만 입력 가능합니다.’ 라는 Error와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
- 이 값이 1과 45 사이의 정수가 아니라면 ‘[ERROR] 보너스 번호는 1과 45 사이의 정수여야 합니다.’ 라는 Error와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
- 이 값이 위의 당첨 번호와 중복된다면 ‘[ERROR] 당첨 번호와 중복되는 번호는 보너스 번호가 될 수 없습니다.’ 라는 Error와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
  <br/> - 1등: 6개 번호 일치 / 2,000,000,000원
  <br/> - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  <br/> - 3등: 5개 번호 일치 / 1,500,000원
  <br/> - 4등: 4개 번호 일치 / 50,000원
  <br/> - 5등: 3개 번호 일치 / 5,000원
  <br/>
  <br/>
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다. 이때, 수익률은 소수점 둘째 자리에서 반올림한다.
